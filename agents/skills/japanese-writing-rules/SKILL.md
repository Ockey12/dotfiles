# 日本語表記ルール

日本語の文章を書くとき、以下のルールに従う。これらは読みやすさと表記の一貫性のためのルールである。

## スペースと記号の幅

- 空白スペースは半角を使う
- 数字は半角を使う
- アルファベットは半角を使う
- 丸括弧は半角`()`を使う。全角`（）`は禁止
- 日本語の文章に付随する`！`と`？`は全角を使う
- 上記に記載のない記号も半角を使う。判断に迷う場合はユーザーに確認する

## Markdownの強調

強調するための`**`は禁止。

## 日本語と他の文字の間のスペース

日本語とアルファベット・数字・記号・コード埋め込みの間にスペースを入れてはいけない。

悪い例:
- 私は Apple Watch を装着する
- 私は 25 歳だ
- ここで `method()` を呼び出す

正しい例:
- 私はApple Watchを装着する
- 私は25歳だ
- ここで`method()`を呼び出す

ポイント: スペースが入るのは日本語と非日本語の「境界」である。非日本語どうしの間(例: "Apple"と"Watch"の間)のスペースはそのまま残す。

## ラベルとコロン

`ラベル: 説明`のように半角コロン`:`で語句を導入するときは、コロンの後に半角スペースを1つ入れる。コロンの前にはスペースを入れない。

正しい例:
- ポイント: スペースは半角にする
- 注: これは例外的な規則である

悪い例:
- ポイント:スペースは半角にする
- ポイント : スペースは半角にする

これは「日本語と他の文字の間のスペース」の唯一の例外で、コロンの直後にだけ半角スペースを置く。時刻(`21:59`)やURL、コード中のコロンには適用しない。

## 表記の自動検査

日本語の文章を書いたり編集したりしたあとは、`SCRIPTS/check-writing-rules.pl`(このスキルのディレクトリ基準)で表記ルールへの違反を機械的に検査する。

```bash
perl SCRIPTS/check-writing-rules.pl <対象ファイル.md> [別のファイル.md ...]
```

Markdownの地の文を対象に、以下を検出する。コードブロック・インラインコード・テーブルのセル区切り・行頭のMarkdownマーカーは検査対象から除外される。

- 全角スペース・全角丸括弧・全角数字・全角英字
- その他の全角記号(`：`や`／`など。日本語の文で正しい全角の`！`と`？`は除く)
- 半角の`!`や`?`(日本語の文では全角の`！`と`？`を使う)
- 日本語と英数字・記号・コードの境界に入った半角スペース
- 強調するための`**`

`違反なし`と表示されれば準拠している。違反が報告されたら、該当行(`Lxx`で行番号が示される)を修正し、再度検査して`違反なし`になることを確認する。終了コードは違反ありで1、なしで0を返すため、フックやCIにも組み込める。
